What to remember

  

    
Why three families of setsA Sudoku board is valid when no digit repeats in any row, column or box. Each unit gets its own set, and a set lookup is O(1).

    
Finding the boxInteger-divide both indices by 3. (r // 3, c // 3) maps all 81 cells onto a 3×3 grid of boxes.

    
Cost81 cells, each with three lookups and three inserts. For a fixed 9×9 board that is constant time and constant space. For an n×n board it would be O(n²) for both.

    
What it does not checkIt only checks the digits already placed. It does not tell you whether the board can be completed into a full solution.
